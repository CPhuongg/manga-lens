# manga-lens

Phát hiện panel / chữ / mặt / thân trên một trang manga, sắp thứ tự đọc (phải→trái, có xử lý trang đôi)
và OCR thoại tiếng Nhật (manga-ocr). Mô hình YOLO11s huấn luyện trên Manga109 (chỉ dùng cho học thuật).

- Mã nguồn, số liệu đánh giá, phân tích lỗi: https://github.com/CPhuongg/manga-lens
- Ảnh tải lên chỉ được xử lý trong bộ nhớ, không lưu. Chỉ tải ảnh bạn có quyền sử dụng.
